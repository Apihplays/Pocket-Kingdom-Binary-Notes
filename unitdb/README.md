# Pocket Kingdom — Compendium

**Live: <https://apihplays.github.io/Pocket-Kingdom-Compendium/>**

Offline data plus a single-file web app for looking up Pocket Kingdom units,
their evolution, emblem recipes, materials, and weapon/armor/accessory crafting.

Generated by [`tools/build_unitdb.py`](../tools/build_unitdb.py).

## Files

| File | What |
|---|---|
| `PocketKingdom-Units.html` | **Open this.** Self-contained app (data embedded, works offline): <br>• **Units** — search / race / move / slots / rank filters, sortable stats <br>• **Team Builder** — add units, total slots vs a cap, combined stats <br>• **Emblems** — recipe table (Ore + Item1 + Item2 → Success%) <br>• **Materials** — jewels/ores/other with rarity + effect; filter by shop, see purchase locations, area searches, dungeon rewards and drops, and the crafting/emblem recipes that consume each one <br>• **Crafting** — weapon/armor/accessory recipes (Mold + Ore + 2 materials → Result + effect) |
| `units.json` / `units.csv` | 115 units: class, race, rank, slots, move, SP, HP/ATK/DEF/AGI/DEX/WIS/INT/HIT%, ability, evolution |
| `emblems.json` / `emblems.csv` | 31 emblems / 70 recipes |
| `materials.json` / `materials.csv` | 89 materials: in-game id, category (Jewels/Ores/Other), rarity, effect, plus where to buy/find each one |
| `crafting.json` / `crafting.csv` | 70 crafting recipes across 10 molds, with effect ids |
| `effects.json` / `effects.csv` | 52 effect ids → names |
| `rankup.json` / `rankup.csv` | the guide's rankup chart (109 edges) used to source SP |
| `raw/` | cached source pages (safe to delete) |

## Rebuild

```bash
python3 tools/build_unitdb.py --details --emblems --crafting --rankup --materials --material-details
```

- `--details` fetches each unit page (Ability + "Advances To" evolution)
- `--emblems` fetches the emblem recipe table
- `--materials` fetches the material database (jewels/ores/other)
- `--material-details` fetches each material's page for Purchase In, Dropped By,
  Area Searches and Dungeon Reward (implies `--materials`)
- `--crafting` fetches the crafting chart + effect-id list
- `--rankup` fetches the guide's rankup chart, adds **SP** to units and
  cross-checks it against the scraped evolution
- all cache into `raw/`, so re-runs are instant; omit the flags for a fast index-only rebuild

## Source

- Wayback Machine captures of `pk.warcry.com` (2005-02-10):
  unit index, per-unit `view_unit.phtml?id=N` pages, and `items/emblems.phtml`
  (2005-02-07) for emblem recipes, plus `items/materials.phtml`
  (2006-09-01) for the material database and `items/view_material.phtml?id=N`
  (2006-09-08) for each material's shops, drops, area searches and dungeons.
- Crafting chart and effect-id list: a plain-text community guide
  (gist `Apihplays/636c34a342b070188780f7f0a417d290`). Only the structured
  recipe/effect data is reproduced, not the guide prose.

## Caveats

- Unit stats are **base** values from the 2005 capture; the retail game scales
  HP/stats with level, and combining/evolving changes them.
- The warcry column labelled **Class** is the unit *name*; **Race** is its family
  (e.g. Class `Soldier`, Race `Warrior`).
- Success rates are the vanilla values (emblems mostly 90%, crafting 5–40%).
  With the repo's 100% combine-rate patch applied, these always succeed.
- Crafting effect ids are matched by name against the guide's effect list; every
  one of the 70 recipes maps. The source chart has typos (`HPAbsortiopn1`,
  `GoldRecoveryUP1`) which are normalised for matching but shown as written.
- Creating an emblem also consumes a **RankUp mold** (sold in the Shop from map 2).
- The material list is 89 items, not the full 1–96 id range: the 2006 capture
  omits ids 83–89. Rarity is the site's own value (higher = rarer).
- A material's **Used in** count only covers the 70 crafting recipes and 70
  emblem recipes in this database, so 21 of the 89 show no uses yet (bloods,
  books, potions, …) even though they are craftable ingredients in game.
  Matching normalises names because the crafting guide spells them without
  spaces (`GaiaRock`, `ChrysaorEye`).
- Shop / drop / search data only exists where the archived material page had it:
  every field defaults to empty, and some high-rarity materials list only a
  dungeon. `Offline` / `Online` under **Area searches** are the site's own labels
  for single-player and online search availability.
- Dropped-by unit names are clickable and open that unit's stats + evolution.
- The Team Builder slot cap is your own planning number.

## Cross-check: two independent sources

The scraped evolution tree (warcry, 2005) and the guide's rankup chart were
compared edge by edge:

- **108 of 108 shared edges agree** on rank, level, VP and RankUp Emblem.
- The guide is missing **`Primitive Cell -> O'Rosam`** (rank 9, level 20, 300 VP)
  — the guide is explicitly incomplete, so this is an omission, not a conflict.
- One genuine **conflict**: the guide says `Master Monk -> Master Fist`, while
  the scraped data says `Expert Monk -> Master Fist` (and gives Master Monk no
  further evolution). Both sources agree that `Expert Monk -> Master Monk`
  (rank 8, lvl 4, 250 VP, Champion Emblem). Keep the scraped edge unless you can
  confirm in game.

**SP** comes only from the guide and is recorded for 19 of 87 source units
(Soldier 11, Warrior 13, Monk 17, ...). The guide lists it once per unit, so it
is stored on the unit, not per evolution edge.
