# Pocket Kingdom — Unit & Emblem database

Offline data plus a single-file web app for looking up Pocket Kingdom units,
their evolution, and emblem recipes.

Generated by [`tools/build_unitdb.py`](../tools/build_unitdb.py) from archived
[pk.warcry.com](http://pk.warcry.com) captures.

## Files

| File | What |
|---|---|
| `PocketKingdom-Units.html` | **Open this.** Self-contained app (data embedded, works offline): <br>• **Units** — table with search / race / move / slots / rank filters and sortable stats <br>• **Team Builder** — add units, see total slots vs a cap and combined stats <br>• **Emblems** — recipe table (Ore + Item1 + Item2 → Success%) |
| `units.json` | 115 units: class, race, rank, slots, move, HP/ATK/DEF/AGI/DEX/WIS/INT/HIT%, ability, evolution |
| `units.csv` | same data, spreadsheet-friendly |
| `emblems.json` / `emblems.csv` | 31 emblems / 70 recipes |
| `raw/` | cached source pages from the Wayback Machine (safe to delete) |

## Rebuild

```bash
python3 tools/build_unitdb.py --details --emblems
```

- `--details` fetches each unit page (Ability + "Advances To" evolution)
- `--emblems` fetches the emblem recipe table
- both cache into `raw/`, so re-runs are instant; omit the flags for a fast index-only rebuild

## Source

Wayback Machine captures of pk.warcry.com:

- `units/` (2005-02-10) — unit index
- `units/view_unit.phtml?id=N` — ability + evolution table
- `items/emblems.phtml` (2005-02-07) — emblem recipes

## Caveats

- Stats are **base** values from the 2005 capture; the retail game scales HP/stats with level, and combining/evolving changes them.
- The site's column labelled **Class** is the unit *name*; **Race** is its family (e.g. Class `Soldier`, Race `Warrior`).
- Emblem success rates here are the vanilla values (mostly 90%). With the repo's
  100% combine-rate patch applied, those recipes always succeed.
- The Team Builder slot cap is your own planning number.
